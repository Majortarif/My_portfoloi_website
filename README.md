## 🌐 Live Demo

## ✨ Key Features
- **Professional Overview:** Highlights my CSE background, education at East West University, and career goals in AI/ML.
- **Projects Showcase:** Interactive display of core technical projects including:
  - *Air Quality Prediction Using Machine Learning & XAI*
  - *EcoBin 2.0 - Next-Generation AI-Powered Smart Waste Bin*
  - *AI-Powered Short Advertisement Creation*
- **Skills Matrix:** Categorized view of technical skills (Machine Learning, XAI, Data Analysis, SQL, Figma, UI/UX, and Digital Marketing).
- **Responsive & Modern Design:** Built with a clean, sleek UI layout optimized for both desktop and mobile screens.
